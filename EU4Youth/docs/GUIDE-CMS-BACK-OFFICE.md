# Guide CMS — EU4Youth

Guide simple pour utiliser le back-office du site EU4Youth.

**Adresse :** https://preprod2026.prodexo.agency/eu4youth/admin/

---

## 1. Connexion

1. Ouvrez le lien ci-dessus.
2. Connectez-vous avec l’email et le mot de passe fournis par l’équipe.
3. Vous arrivez sur le **Tableau de bord**.

Astuce : si la page ne se met pas à jour après un déploiement, faites un **Ctrl + Maj + R** (rechargement forcé).

---

## 2. Menu principal

| Menu | À quoi ça sert |
|------|----------------|
| **Tableau de bord** | Vue d’ensemble |
| **Contenu du site** | Textes des pages (accueil, à propos, etc.) |
| **Aperçu live** | Voir le site et éditer en direct |
| **Traductions** | Libellés FR / EN / AR du menu et de l’interface |
| **Six projets** | Fiches Jeun’ESS, Fe3il.a, Maghroum’IN, SWAFY, GO4Youth, IRADA4YOUTH |
| **Actualités** | Articles publiés sur `/actualites` |
| **Publications** | Rapports, newsletters, PDF |
| **Agenda** | Événements |
| **Initiatives / carte** | Points de la carte interactive |
| **Youth Stories** | Portraits de jeunes |
| **Vidéothèque** | Vidéos YouTube |
| **Opportunités** | Appels, formations, bourses |
| **Glossaire** | Définitions |
| **Formulaires** | Messages contact + newsletter |
| **À valider** | Fiches en attente de publication |
| **Historique** | Qui a modifié quoi |
| **Utilisateurs / Rôles** | Comptes et droits (admins) |

Vous ne voyez que les menus autorisés pour votre rôle.

---

## 3. Modifier une fiche (Actualités, Publications, Agenda…)

1. Ouvrez le menu (ex. **Actualités**).
2. Cliquez sur une ligne, ou sur l’icône crayon.
3. Remplissez les champs.
4. Choisissez la langue avec les onglets **Français / English / العربية**.
5. Statut :
   - **Brouillon** = pas visible sur le site
   - **Publié** = visible sur le site
6. Laissez cochée **Traduire EN / AR à l’enregistrement** si vous voulez synchroniser les autres langues automatiquement.
7. Cliquez **Enregistrer**.
8. **Retour** pour revenir à la liste.

### Créer une fiche

Cliquez **+ Nouvelle fiche**, puis remplissez et enregistrez.

### Actions dans la liste

- Œil / lien = aperçu sur le site
- Crayon = modifier
- Double page = dupliquer
- Poubelle = supprimer

---

## 4. Six projets

1. Allez dans **Six projets**.
2. Cliquez sur une carte (Jeun’ESS, GO4Youth…).
3. Modifiez le nom, l’accroche, la présentation, les objectifs, les KPI, les composantes.
4. Passez en EN / AR avec les onglets si besoin.
5. **Enregistrer**.

Ces fiches alimentent `/projets` et chaque page projet du site public.

---

## 5. Contenu du site (pages)

1. Ouvrez **Contenu du site**.
2. Choisissez une page dans la colonne de gauche (Accueil, À propos…).
3. Modifiez les blocs de texte.
4. Enregistrez.

Pour voir le rendu réel : utilisez **Aperçu live**.

---

## 6. Aperçu live

1. Ouvrez **Aperçu live**.
2. Naviguez dans le site comme un visiteur.
3. Les zones éditables sont cliquables.
4. Enregistrez vos changements depuis la barre d’outils.

Utile pour vérifier le résultat avant de partager un lien.

---

## 7. Initiatives / carte

Chaque fiche = un point sur la carte.

- **Gouvernorat** obligatoire
- Liez le bon **projet**
- Statut **Publié** pour apparaître sur `/carte`

---

## 8. Formulaires (inbox)

1. Ouvrez **Formulaires**.
2. La liste montre contact + newsletter.
3. Cliquez une ligne pour lire le message.
4. Vous pouvez **archiver** ou **supprimer**.

---

## 9. Langues FR / EN / AR

- Sur chaque fiche, utilisez les onglets de langue.
- Le site public change de langue via le sélecteur du header.
- Si un onglet est marqué manquant, complétez ou laissez la traduction auto à l’enregistrement.

---

## 10. Bonnes pratiques

- Travaillez d’abord en **Français**, puis EN / AR.
- Mettez en **Brouillon** pour préparer, **Publié** seulement quand c’est prêt.
- Vérifiez sur le site public après enregistrement (Ctrl + Maj + R).
- Pour un PDF : uploadez le fichier côté docs / indiquez le lien dans la publication.
- Ne supprimez une fiche que si vous êtes sûr·e.

---

## 11. Rôles (résumé)

| Rôle | Peut surtout… |
|------|----------------|
| **Administrateur** | Tout |
| **Éditeur** | Contenu + catalogues + validation |
| **Contributeur** | Fiches de son projet (souvent à valider) |
| **Communication** | Selon les droits donnés |

---

## 12. En cas de problème

| Problème | Que faire |
|----------|-----------|
| Page blanche / ancienne version | Ctrl + Maj + R |
| Impossible de se connecter | Vérifier email / mot de passe ; demander un reset à l’admin |
| Modification invisible sur le site | Vérifier le statut **Publié** ; recharger le site |
| Menu manquant | Demander les droits à l’administrateur |
| Erreur à l’enregistrement | Réessayer ; sinon noter l’heure et prévenir l’équipe technique |
